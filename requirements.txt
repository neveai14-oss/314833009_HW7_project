# Base app requirements
# ---------------------
# The default Flow Matching demo uses only Python standard library modules.
# No mandatory third-party package is required to run:
#
#   python src/server.py
#

# - Ollama: install and run the Ollama desktop/server app separately.
# - OpenRouter: set OPENROUTER_API_KEY in the environment.
# - Stable Diffusion XL GPU mode: install requirements-stable-diffusion.txt.
